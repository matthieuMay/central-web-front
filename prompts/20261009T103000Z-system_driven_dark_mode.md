# System-driven Dark Mode

- **Thème initial** : Utiliser la préférence de couleur du système d'exploitation au chargement sur les pages `/` et `/board`.
- **Bascule manuelle** : Ajouter un bouton visible dans le `Header` pour basculer entre le mode clair et le mode sombre de manière temporaire.
- **Absence de persistance** : Ne pas sauvegarder le choix manuel ; lors d'un rechargement de la page, l'application doit repartir de la préférence système actuelle.
- **Validation** : Le texte, les cartes, les colonnes et les contrôles doivent rester parfaitement lisibles dans les deux thèmes.
