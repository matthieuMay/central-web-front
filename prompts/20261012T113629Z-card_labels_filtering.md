Let's start with n°1 ### Card labels and filtering

The idea :
- one color specifies the label (red for urgent, blue for documentation, yellow for bug, green for feature, etc...)
- when creating a card or editing a card, the label/color can be specified by user (no label by default)
- the indicator is bottom right of the card, represented by a full-colored circle
- a pallet is on top of the board to filter which cards are to be shown in the board (by default every color are selected; user can click on one color to select/deselect it from the board; when deselected the color form the pallet is opacity 25%)
- once a card reached the last column, the circle bottom right disappears (needs to reappear if card in last column is moved again in other columns)
