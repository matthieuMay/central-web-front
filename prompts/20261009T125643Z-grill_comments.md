# Grill comments

I want to improve my Trello-like application by upgrading cards with card comments:
- show up to three latest comments below the description and above the checklist;
- provide a left-side drawer for all comments, creation, and deletion;
- choose comment authors from API users;
- let the API set `createdAt` on creation.

Use the provided `CommentData` and `CardData` types, preserve existing assignee/checklist behavior, inspect the existing app and docs, and do not implement before the design is agreed.
