# User prompt

Improve the Trello-like application's add-card interaction by replacing the inline add-card form with an "Add a card" trigger and a centered popup form. The popup should support title and description, dismiss on outside click or Escape, preserve the existing API contract, match the current theme, show a three-second success message after creation, and use blue-ish theme-aware add-card buttons. Reuse the blank `AddCardPopup.tsx` component. Do not change unrelated components. Validate with lint, dev server, and manual browser testing. Do not implement before the user confirms.
