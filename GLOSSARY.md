# Glossary

## Main task

A board card that represents the primary piece of work and owns an ordered collection of subtasks.

## Subtask

A first-class unit of work belonging to one main task. It has a stable identity, a title, an order within its parent task, and a completion state.

## Session user

The user selected for the current page session and used as the author identity for comments created during that session.

## Anonymous session

A page session in which no named user is selected. Anonymous visitors can read the board and existing comments but cannot create comments.

## Display name

The user-facing name resolved from an API user record and used when identifying a session user or authoring a new comment.

## Subtask handle

A dedicated double-arrow up/down control that is the only draggable surface for reordering a subtask. It is distinct from the main task's drag surface.
