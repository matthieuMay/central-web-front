# Central Web Front

This glossary defines the user-facing theme concepts used across the application.

## Language

**Theme**:
The light or dark visual presentation applied to the application.

**System preference**:
The operating system's current light-or-dark color-scheme preference used to initialize and, until overridden, update the application's theme.
_Avoid_: Browser theme, device theme

**Manual override**:
A light-or-dark choice made through the application's Header control that takes precedence over later system preference changes until the page is reloaded.
_Avoid_: Saved preference, persistent theme
