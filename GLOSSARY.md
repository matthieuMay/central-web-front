# Mini-Trello

This context describes the shared task board and its presentation preferences.

## Language

**Theme mode**:
The presentation preference selected for the application: System, Light, or Dark.
_Avoid_: Theme, color mode

**System mode**:
A theme mode that follows the operating system or browser appearance preference and updates when that preference changes.
_Avoid_: Automatic mode

**Light mode**:
An explicit theme mode using the light application palette for the current visit.
_Avoid_: Bright mode

**Dark mode**:
An explicit theme mode using the dark application palette for the current visit.
_Avoid_: Night mode
