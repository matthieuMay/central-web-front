# Mini-Trello Front

Student repo — Vite + React + TypeScript. Reset between Étapes with git tags (`start/…`, `end/…`).

Clone only; submit zip/USB. Do not push to this remote.

## Quick start

```bash
npm install
npm run dev
```

API (Sprint 3+): see `central-web-api`, set `VITE_API_URL` in `.env`.

## Tags (Étapes)

| Tag | Meaning |
|---|---|
| `start/j1-squelette` … `end/j1-squelette` | Header / Layout |
| `start/j2-sprint1-props` … | Board / Column / Card + mock JSON |
| `start/j2-sprint2-state` … | useState, lift state up |
| `start/j3-sprint3-api` … | fetch API |
| `start/j3-sprint4-dnd` … | dnd-kit |

`end/*` = corrected target (use if stuck to continue).
